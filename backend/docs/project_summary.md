# TalentSync — Project Summary

## Overview
TalentSync is a full-stack job and talent management application. It uses a Django backend to provide REST APIs and business logic, and a React + Vite frontend for the user interface.

## Repository Structure (high level)
- `backend/` — Django project and apps
  - `talentsync_backend/` — Django project settings and entrypoints
  - `applications/` — application flow, serializers, email templates
  - `companies/` — employer profiles, permissions, serializers
  - `jobs/` — job postings, filters, views
  - `users/` — user models, permissions, auth
- `frontend/` — React app scaffolded with Vite

## Tech Stack
- Backend: Python, Django, Django REST Framework
- Frontend: React, Vite
- Dev: `manage.py`, `requirements.txt`, `package.json`

## Backend Details
- Apps and responsibilities:
  - `applications`:
    - API endpoints for creating and managing job applications
    - Email templates (`templates/applications/emails`) used to send confirmations
    - Serializers and views that validate and persist application data
  - `companies`:
    - Models and serializers for company/employer profiles
    - Permissions to restrict company actions to authorized users
  - `jobs`:
    - Job posting models, filters, and views for listing and searching jobs
    - Permissions to control create/update/delete operations
  - `users`:
    - Custom user models/serializers and auth-related views
- Migrations present in each app record schema changes under `migrations/`.

## Frontend Details
- Located in `frontend/` — uses Vite for dev server and bundling
- `src/` contains `App.jsx`, `main.jsx` and styles. The frontend consumes the backend REST APIs to display jobs, allow applications, and manage user/company actions.

## Features You Implemented (concise but detailed)
- Designed and implemented core Django models for jobs, companies, applications, and users.
- Built serializers and API views (DRF) to expose backend functionality to the frontend.
- Implemented email confirmation templates and wiring to send application confirmation emails.
- Added permission classes and filters to secure endpoints and add search/filter functionality.
- Created frontend scaffolding with React and Vite to interact with the APIs.
- Added database migrations to persist schema changes and included tests where available.

## Setup & Run (local)
Backend (from `backend/`):

1. Create and activate a Python virtual environment:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1  # PowerShell
```

2. Install Python dependencies:

```powershell
pip install -r requirements.txt
```

3. Apply migrations and run server:

```powershell
python manage.py migrate
python manage.py runserver
```

Frontend (from `frontend/`):

```bash
npm install
npm run dev
```
