# TalentSync Frontend

This frontend is a Vite React app for TalentSync.

## Pages and roles

- Welcome screen for signed-out visitors
- Login and register flow
- Employer dashboard for company profile and vacancy management
- Job seeker dashboard for browsing vacancies and applying to jobs

## Employer flow

1. Register as an employer
2. Create a company profile
3. Add, edit, close, or remove vacancies
4. Review applicants and update application status

## Job seeker flow

1. Register as a job seeker
2. Fill in a simple profile
3. Browse jobs by company
4. Apply to a job and track submitted applications

## Run locally

1. Start the backend on port 8000
2. Start the frontend with `npm run dev`
3. Log in and use the dashboard that matches your role
